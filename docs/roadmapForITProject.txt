1. Week 01: Course orientation and project choice
Meeting length: 3 hours. The meeting combines review, guided technical work, project development, and a closing checkpoint.
Workshop focus: Compare the ten topics, identify users and constraints, and choose an initial problem statement.
In-class instructions:
1. Review the project state and identify the most important question for this meeting.
2. Compare the ten topics, identify users and constraints, and choose an initial problem statement.
3. Work on the project and record decisions, code changes, and evidence in the repository or project notes.
4. At the end, demonstrate the result and note the next action and any blocker.
Expected evidence: A one-page project concept with objectives, intended users, proposed features, risks, and open questions.
Related milestone: M1: Project Proposal and Scope. This is a course sequence label, not a due date.
